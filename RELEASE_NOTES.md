# PeaBox Photo Lab v0.2.26

Cumulative feature release built from v0.2.25 with all previous functionality retained.

## New features
- Edge Fade: adjustable strength and selectable edge colour for soft framing effects.
- Rule-of-Thirds Grid: preview-only composition guide that does not alter exported images.
- Composition Advisor: classifies the edited image as Landscape, Portrait, or Balanced and provides practical output guidance.
- Story Portrait preset: JPEG quality 92, 2560 px long edge.
- Slide Ready preset: JPEG quality 93, 2048 px long edge.
