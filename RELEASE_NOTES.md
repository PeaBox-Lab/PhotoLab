# PeaBox Photo Lab v0.2.17

Cumulative feature release built from v0.2.16. All earlier features are retained.

## New features
- Black Point control from 0-80 and White Point control from 175-255 for direct tone-range remapping.
- Auto Temperature Correction from 0-100 for automatic red/blue cast balancing.
- Focus Analysis in Image Inspector with an edge-focus score and guidance for soft or over-sharpened images.
- Desktop Wallpaper preset: JPEG quality 93, 4096 px long edge.
- Fast Preview preset: WebP quality 76, 1080 px long edge.
