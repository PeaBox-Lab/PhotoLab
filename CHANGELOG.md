# Changelog

## 0.2.6
- Added Posterize and Solarize creative effects.
- Added RGB Channel Mixer for independent red, green, and blue balancing.
- Added Privacy PNG export preset for metadata-free lossless exports.
- Added megapixel reporting to export preview.
- Retained all v0.2.5 functionality.


## 0.2.5
- Added Portrait Soft, Cinematic, and High Key quick styles.
- Added adjustable Clarity and Noise Reduction tools.
- Added Email Compact and 4K Display export presets.
- Expanded the preset proof sheet to include all new styles.
- Retained all v0.2.4 functionality.


## 0.2.4
- Added adjustable Sepia effect.
- Added Exposure Analysis with luminance, contrast, deep-shadow, and bright-highlight metrics.
- Added automatic exposure guidance.
- Fixed the v0.2.3 custom export dimension path to resize the active edited image correctly.
- Retained all previous features.


## 0.2.3
- Added Black & White and Negative quick effects.
- Added custom export dimensions with optional aspect-ratio preservation.
- Added live output dimensions and encoded file-size preview.
- Retained all v0.2.2 features and export presets.


## 0.2.2
- Added reusable export presets: Web High Quality, Social 1080, and Archive PNG.
- Retained Custom export mode and all v0.2.1 functionality.
- Updated version metadata, README, release notes, and package naming.


## 0.2.1
- Normalized project versioning to semantic three-part format `99.99.99`.
- Standardized release archive naming as `peabox-photo-lab-v<version>.zip`.
- Retained the complete existing photo editing, creator toolkit, image inspector, privacy, and export feature set.
- Updated application and package metadata for this release.
