# Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community. Be constructive, respect differing viewpoints, accept responsibility for mistakes, and focus on what is best for users and contributors. Unacceptable behavior includes harassment, discriminatory language, threats, doxxing, and publishing private information without permission. Maintainers may remove content or participation that violates these expectations. Report concerns privately through the security or maintainer contact configured for the repository.
